# 🧾 TU Reports  
**ระบบแจ้งปัญหาและติดตามการแก้ไขภายในมหาวิทยาลัยธรรมศาสตร์**

---

## 📘 Overview  
**TU Reports** คือระบบเว็บแอปพลิเคชันที่พัฒนาขึ้นเพื่อใช้ในการ **แจ้งปัญหาและติดตามการแก้ไขภายในมหาวิทยาลัยธรรมศาสตร์**  
โดยผู้ใช้งาน (นิสิต / อาจารย์ / เจ้าหน้าที่) สามารถรายงานปัญหาที่พบ เช่น อุปกรณ์ชำรุด อินเทอร์เน็ตล่ม หรือห้องเรียนไม่พร้อมใช้งาน ถนนชำรุด ไฟฟ้าขัดข้อง ได้อย่างสะดวก รวดเร็ว และโปร่งใสผ่านระบบออนไลน์  

เจ้าหน้าที่ผู้รับผิดชอบ อัปเดตสถานะ และแนบหลักฐานหลังการแก้ไขได้โดยตรง  
นอกจากนี้ ระบบยังมีแดชบอร์ดสรุปผลและรายงานสถิติของปัญหาที่เกิดขึ้น เพื่อให้ผู้ดูแลสามารถวิเคราะห์แนวโน้มและปรับปรุงการบริหารจัดการได้อย่างมีประสิทธิภาพ  

---

## 🎯 Project Goals  
-	พัฒนาเว็บแอปพลิเคชันที่ช่วยให้ผู้ใช้งานสามารถแจ้งปัญหาได้อย่างสะดวก รวดเร็ว 
-	สร้างระบบติดตามงานแบบเรียลไทม์ เพื่อให้ผู้แจ้งสามารถตรวจสอบสถานะได้ทุกขั้นตอน
-	เพิ่มประสิทธิภาพการรับเรื่องและการแก้ไขของเจ้าหน้าที่ ผ่านการจัดการงานที่เป็นระบบ
-	จัดทำแดชบอร์ดและรายงานสถิติ เพื่อใช้เป็นข้อมูลประกอบการปรับปรุงคุณภาพการให้บริการภายมหาวิทยาลัย
